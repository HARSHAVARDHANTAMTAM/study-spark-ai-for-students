# StudySpark AI

Build a modern AI-powered web application called "StudySpark AI" for students.

Purpose:

StudySpark AI is an AI Study Buddy that helps students upload study materials, understand difficult concepts, ask questions, generate quizzes, create revision plans, and monitor learning progress using IBM Bob AI.

Theme:

Modern educational SaaS application.

Use a clean blue, purple, and white color palette.

Rounded cards, smooth animations, glassmorphism, modern gradients, and responsive design.

Professional UI similar to Notion AI, Perplexity, and ChatGPT.
